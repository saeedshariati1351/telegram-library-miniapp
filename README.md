# کتابخانهٔ تلگرامی — مینی‌اپ

مینی‌اپ تلگرام برای مرور و جستجوی کتاب‌های PDF کانال‌های پوشهٔ «کتابخانه».

- **خانه:** جستجو، دسته‌ها، تازه‌ها، پیشنهاد روز، مرور بر اساس کانال
- **صفحهٔ کتاب:** پیوند «خواندن در تلگرام» به PDF در کانال اصلی، و «نسخه‌های دیگر در کانال‌ها» برای همان کتاب در کانال‌های دیگر؛ مشخصات کتاب‌شناختی (فیپا)
- **صفحهٔ نویسنده:** همهٔ تألیف‌ها و ترجمه‌های هر نفر با فیلتر
- **جلد:** تصویر جلد از ستون «تصویر جلد» اکسل (عکس پست کانال)، وگرنه از وب با شابک (Open Library)، وگرنه جلد پیش‌فرض رنگی با عنوان
- **نشان‌شده‌ها:** در CloudStorage تلگرام ذخیره می‌شود و روی همهٔ دستگاه‌های کاربر می‌ماند

## به‌روزرسانی فهرست کتاب‌ها

```
pip install openpyxl
python3 tools/excel_to_json.py catalog.xlsx data/books.json
git commit -am "به‌روزرسانی فهرست" && git push
```

## کتابخانه‌های آنلاین (نسخهٔ ۷)

دادهٔ کتابخانه‌های آنلاین در مخزن جداگانهٔ `telegram-library-online` است (به‌خاطر سقف ۱ گیگابایتی GitHub Pages).
هر کتابخانه یک فایل اکسل دارد (ساخته‌شده از شاخه‌های `h-*` گردش‌کار «جمع‌آوری کتابخانه‌های آنلاین»، پوشهٔ `harvest/`).

```
python3 tools/build_online.py <پوشهٔ اکسل‌ها> data/ ../telegram-library-online/
```

این ابزار:
- کتاب‌هایی را که در کانال‌های تلگرامی هم هستند (عنوان + جلد + پدیدآور + مترجم یکسان) پیدا می‌کند و پیوند آنلاین را به «نسخه‌های دیگر» همان کتاب در `data/w/` می‌افزاید (و دفعهٔ بعد، با `attached.json`، اول آن‌ها را پاک می‌کند)
- بقیه را با شناسهٔ ۲٬۰۰۰٬۰۰۰ به بالا در مخزن آنلاین می‌سازد؛ کتابخانه‌ها در مینی‌اپ شمارهٔ ۱۰۰۰ به بالا دارند
- مینی‌اپ (`config.js` ← `onlineBase`) هر دو نمایه را با هم جستجو می‌کند

`tools/add_online.py` (روش نسخهٔ ۴، افزودن در همین مخزن) کنار گذاشته شده است.

سایت ایستا است (HTML/CSS/JS بدون ساخت) و روی GitHub Pages میزبانی می‌شود.
