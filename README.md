# کتابخانهٔ تلگرامی — مینی‌اپ

مینی‌اپ تلگرام برای مرور و جستجوی کتاب‌های PDF کانال‌های پوشهٔ «کتابخانه».

- **خانه:** جستجو، دسته‌ها، تازه‌ها، پیشنهاد روز، مرور بر اساس کانال
- **صفحهٔ کتاب:** پیوند «خواندن در تلگرام» به PDF در کانال اصلی، و «نسخه‌های دیگر در کانال‌ها» برای همان کتاب در کانال‌های دیگر؛ مشخصات کتاب‌شناختی (فیپا)
- **صفحهٔ نویسنده:** همهٔ تألیف‌ها و ترجمه‌های هر نفر با فیلتر
- **جلد:** تصویر جلد از ستون «تصویر جلد» اکسل (عکس پست کانال)، وگرنه از وب با شابک (Open Library)، وگرنه جلد پیش‌فرض رنگی با عنوان
- **نشان‌شده‌ها:** در CloudStorage تلگرام ذخیره می‌شود و روی همهٔ دستگاه‌های کاربر می‌ماند

## به‌روزرسانی فهرست کتاب‌ها

```
pip install openpyxl
python3 tools/excel_to_json.py catalog.xlsx data/books.json
git commit -am "به‌روزرسانی فهرست" && git push
```

سایت ایستا است (HTML/CSS/JS بدون ساخت) و روی GitHub Pages میزبانی می‌شود.
